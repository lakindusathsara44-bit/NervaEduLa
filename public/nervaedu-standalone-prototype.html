Quick guide

How NervaEdu works

A simple walkthrough for both sides of the classroom.

①

Create a demo account

Choose Student or Teacher, then sign up. This prototype saves the demo profile only in this browser.

②

Find or publish a course

Students browse available courses. Teachers can create courses and add video links, paper links and quiz questions.

③

Keep learning

Open a course, view materials and try the built-in sample quiz. Your prototype activity is stored locally.

Prototype limitations

This is a front-end demo. Accounts and course data are stored in local browser storage, not a secure server. Do not use real passwords or confidential student data. A production LMS needs a backend, database, secure authentication, file storage and access controls.
